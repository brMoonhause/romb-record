# РОМБ D5 — реактивна модель для рекорду швидкості

Літаюче крило-ромб 1000 × 800 мм, двигун jet 200 відкрито в ніші, сопло на задній кромці.

## Файли
| Файл | Що це |
|---|---|
| `params.py` | таблиця параметрів: перерізи, ніша, двигун, елевони, кілі (мм) |
| `foils.py` | профілі: NACA 4-digit, modified 4-digit (00tt-64), тіло BODY-150 |
| `romb_b123d.py` | збирання моделі кодом (build123d) → `romb_d5_jet200.step` |
| `romb_d5_jet200.FCMacro` | та сама модель для FreeCAD в одному файлі (Macro → Execute) |
| `romb_d5_jet200.step` | деталі окремо: крило, 4 елевони, 2 кілі, двигун |
| `romb_d5_jet200.FCStd` | документ FreeCAD з тими самими деталями |

## Як перебудувати
```
pip install build123d
python romb_b123d.py
```
У FreeCAD: Macro → Macros… → вибрати `romb_d5_jet200.FCMacro` → Execute.
Параметри для макроса — у його верхній частині (копія `params.py`).

## Поточна геометрія (варіант D, двигун jet 200)
- Передня кромка 78° до x=600, далі 40°; задня кромка 10° уперед, корінь 1000, кінці 929.
- Тіло BODY-150 продовжене до x=778 (губа входу jet 200), ніша ±59 мм.
- Елевони: вісь шарнірів x=890, внутрішні 72–200, зовнішні 200–400 мм.
- Кілі: y=±200, корінь 200, кінець 110, NACA 0005, нахил 5° назовні.
- Двигун jet 200: Ø109 × 249 мм, сопло Ø54 на x=985 (спрощене тіло обертання).

## Двигун jet 200 (дані від власника)
- Тяга 21 кгс (206 Н) на 121 000 об/хв, EGT до 750 °C, витрата 590 г/хв, паливо дизель / Jet A1 / гас, мастило 5 %.
- Насос KP800BL (S.BUS). Маса в розрахунку 1,74 кг — за паспортом KingTech K-210G4+, підтвердити зважуванням.

## Оцінки (26.11.2026)
- Vmax ≈ 785 км/год (рекорд 749 км/год, запас ~5 %); опір відкалібровано за попереднім розрахунком з P250.
- Злітна маса ≈ 8,8 кг (паливо 2,16 кг на той самий час польоту), центр мас ≈ 613 мм, запас стійкості ≈ 10 % (НТ 672 — перевірити у XFLR5 для нової ніші).
- Порожні баки: центр мас ≈ 612 мм.

## Відкриті питання
- Перерахунок нейтральної точки у XFLR5 для продовженого тіла і ніші ±59 мм.
- Повітрозабірники і S-канали ще не змодельовані.
