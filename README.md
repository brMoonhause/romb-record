# РОМБ D5 — реактивна модель для рекорду швидкості

Літаюче крило-ромб 1000 × 800 мм, двигун jet 200 відкрито в ніші, сопло на задній кромці.

## Файли
| Файл | Що це |
|---|---|
| `params.py` | таблиця параметрів: перерізи, ніша, двигун, елевони, кілі (мм) |
| `foils.py` | профілі: NACA 4-digit, modified 4-digit (00tt-64), тіло BODY-150 |
| `geom.py` | геометрія як точки: перерізи крила, обтічник, повітрозабірники й S-канали |
| `fc_build.py` | побудова у FreeCAD (з неї збирається макрос) |
| `romb_b123d.py` | збирання моделі кодом (build123d) → `romb_d5_jet200.step` |
| `romb_d5_jet200.FCMacro` | та сама модель для FreeCAD в одному файлі (Macro → Execute); генерується з params+foils+geom+fc_build |
| `romb_d5_jet200.step.zip` | STEP (з build123d, у zip через ліміт GitHub 100 МБ): корпус, 4 елевони, 2 кілі, двигун |
| `romb_d5_structure.step.zip` | STEP внутрішнього набору: стінки, шпангоути, лонжерони, нервюри, серво, шарніри |
| `romb_d5_jet200.FCStd` | документ FreeCAD v4 (корпус, елевони, кілі, двигун, внутрішній набір у групі Structure) |

## Як перебудувати
```
pip install build123d
python romb_b123d.py
```
У FreeCAD: Macro → Macros… → вибрати `romb_d5_jet200.FCMacro` → Execute.
Параметри для макроса — у його верхній частині (копія `params.py`).

## Поточна геометрія (v6, двигун jet 200)
- Передня кромка 78° до x=600, далі 40°, **злами заокруглені** (LE_BLEND); задня кромка 10° уперед, корінь 1000, кінці 929.
- **Гладка поверхня**: товщина між станціями інтерполюється монотонним кубічним сплайном (PCHIP) по розмаху, корпус — гладкий B-сплайновий loft через 37 перерізів (раніше — лінійчатий між 8 станціями зі зламами).
- **Ніші немає**: профілі корпусу і крила тягнуться до самого двигуна; відсік = контур двигуна + 5 мм зазору під теплоізоляцію; де двигун товщий за крило (x > ~830), корпус двигуна виходить назовні. Канал вихлопу Ø64 за соплом прорізає задню кромку.
- **Повітрозабірники** (2 шт) **вписані в товщину крила** — нічого не виступає: вхід у площині x=480 має форму перерізу крила між y≈64 і 94 мм (висота до 83 мм, площа 14,3 см²), губа 4 мм — це обшивка, заокруглена еліптично на 22 мм; перед входом у передній кромці виїмка (від x≈283 на внутрішньому краю), внутрішня стінка виїмки — бік корпусу.
- **Канали**: ≈210 мм, з форми перерізу крила плавно в коло, площа 14,3 → 13 (горло) → 20 см² (×1,54, екв. напівкут 1,3°), один плавний S-вигин до 32°; обидва виходять у **спільну камеру** перед двигуном.
- **Камера**: Ø116 мм від x=640 до двигуна (≈106 см², швидкість ≈34 м/с статично), далі відсік двигуна з зазором 5 мм.
- Елевони: вісь шарнірів x=890, щілина 1 мм; внутрішні 72–195, зовнішні 205–400 мм; між ними нерухома смужка 195–205 під задню частину кореня кіля.
- Кілі: y=±200, корінь 200, кінець 110, NACA 0005, нахил 5° назовні.
- Внутрішній набір (пластини 2 мм): центральна стінка y=0 (x 60–615), бокові стінки y=±70 (x 580–884, кріплення двигуна), шпангоути 300/450/615/723/806 з отворами під канали, передній лонжерон (35 мм за кромкою), задній лонжерон x=884 (вісь шарнірів), нервюри y=127,5/200/340, 4 сервоприводи (y=135, x=850 і y=220, x=820).
- Двигун jet 200: Ø109 × 249 мм, сопло Ø54 на x=985 (спрощене тіло обертання).

## Розрахунки v3
- Витрата K-210 0,43 кг/с: горло 2×13 см² → M≈0,45 статично; на 785 км/год площа захоплення 16,1 см², MFR≈0,56 (`inlet_calc_v3.py`; `inlet_sweep2.py` — перебір для варіанта v4 з щоками).
- Втрата на скиданні каналів у камеру ≈1,8 % p0 статично (менше на швидкості).
- Вільний об'єм під баки між шп. 450 і 640 (між каналами): ≈3,7 л (потрібно ≈2,7 л палива).
- Набір: ≈2550 см² пластин → ≈0,5 кг (вуглець 2 мм з облегшенням 40 %), ≈0,8 кг без облегшення.
- Шарнірні моменти на 855 км/год: внутрішній елевон 17 кг·см при 5° (34 при 10°), зовнішній 12 (23). Серво 10 мм (напр. KST X10, 10,8 кг·см) — лише з важільною передачею 2:1.

## Двигун jet 200 (дані від власника)
- Тяга 21 кгс (206 Н) на 121 000 об/хв, EGT до 750 °C, витрата 590 г/хв, паливо дизель / Jet A1 / гас, мастило 5 %.
- Насос KP800BL (S.BUS). Маса в розрахунку 1,74 кг — за паспортом KingTech K-210G4+, підтвердити зважуванням.

## Оцінки (26.11.2026)
- Vmax ≈ 785 км/год (рекорд 749 км/год, запас ~5 %); опір відкалібровано за попереднім розрахунком з P250.
- Злітна маса ≈ 8,8 кг (паливо 2,16 кг на той самий час польоту), центр мас ≈ 613 мм, запас стійкості ≈ 10 % (НТ 672 — перевірити у XFLR5 для нової ніші).
- Порожні баки: центр мас ≈ 612 мм.

- Зовнішній об'єм корпусу з елевонами ≈14,4 л (канали й камера вже вирізані).

## Відкриті питання
- Перерахунок нейтральної точки у XFLR5 для продовженого тіла і ніші ±59 мм.
- Кріплення двигуна, баки, парашутний відсік — ще не змодельовані.
